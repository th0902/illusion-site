# 錯視ギャラリー

1ページに1つの錯視を表示する、純粋な HTML/CSS 製の錯視コレクション。画像を一切使わず、すべて CSS で描画しています。

## 収録している錯視（全46種）

幾何学的錯視・明暗/色の錯視・補完の錯視・多義図形・不可能図形・運動/消失/残効まで幅広く収録しています。

- **大きさ・長さ**：エビングハウス / デルブーフ / ジャストロー / ミュラー・リヤー / ポンゾ / 垂直水平 / サンダーの平行四辺形
- **傾き・ゆがみ**：カフェウォール / ツェルナー / ヘリング / ヴント / ポッゲンドルフ / オービソン / フレーザー
- **格子・きらめき**：ヘルマン格子 / きらめき格子 / 大内錯視
- **明暗・コントラスト**：同時対比 / ホワイト / マッハバンド / チェッカーシャドウ / コーンスウィート / ベツォルト効果 / ヴァザルリ / チャブ
- **色・奥行き**：色の残像 / 国旗の残像 / ムンカー / ネオンカラー拡散 / ベンハムのコマ / 色立体視
- **主観的輪郭**：カニッツァの三角形 / カニッツァの四角形 / エーレンシュタイン
- **多義図形**：ネッカーの立方体 / シェパードのテーブル / ヘルムホルツの正方形 / シュレーダーの階段
- **不可能図形**：ペンローズの三角形 / 悪魔のフォーク
- **運動・消失・残効**：蛇の回転 / ライラックチェイサー / トロクスラー効果 / 運動誘発盲 / ピンナ＝ブレルスタッフ / 運動残効（滝の錯視）

## ローカルで見る

```sh
cd illusion-site
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## GitHub Pages で公開する

1. このフォルダを GitHub のリポジトリに push する。
   ```sh
   git add .
   git commit -m "錯視ギャラリーを追加"
   git branch -M main
   git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
   git push -u origin main
   ```
2. リポジトリの **Settings → Pages** を開く。
3. **Source** を `Deploy from a branch`、Branch を `main` / `/ (root)` に設定して保存。
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

## 錯視を追加する

`assets/illusions.js` の `ILLUSIONS` 配列に項目を1つ追加し、必要なら `assets/style.css`
に対応するスタイルを足すだけです。ギャラリー・個別ページ・前後ナビは自動更新されます。
